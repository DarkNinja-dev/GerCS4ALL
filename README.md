# Curated CloudStream DE / EN

Dieses Repository enthält nur nachweislich deutsche oder englische, sprachneutrale bzw. konservativ als unklar markierte Quellen. Die vier Listen sind getrennt nutzbar: `anime`, `hentai`, `ger` und `eng`.

## Einbindung nach dem Push

CloudStream kann dieses Repository über folgende URL einbinden:

`https://raw.githubusercontent.com/DevMonkeyOps/GerCS4ALL/main/repo.json`

Die Einzelkategorien liegen unter `single-repos/<kategorie>/repo.json`.

## Pflege

Die Plugin-URLs zeigen grundsätzlich auf verifizierte Upstream-Repositories. `GerCS4ALLAnime` wird dagegen lokal gebaut, liegt unter `plugins/anime/` und registriert KayoAnime sowie AnimeToast. Seine Kategorien sind ausschließlich `Anime`, `AnimeMovie` und `OVA`.
